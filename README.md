# викторикна - 
Это веб-приложение на ASP.NET Core для создания и прохождения викторин. В проекте реализована регистрация и вход с хешированием паролей, а также будет сохранение входа через постоянные куки. Данные хранятся в бд на Neon. Пользователи могут создавать викторины с вопросами и вариантами ответов, проходить чужие викторины, получать баллы и смотреть свой рейтинг. В личном кабинете отображается сколько викторин пройдено и создано, лучший результат. (КОД В ВЕТКЕ MASTER)
